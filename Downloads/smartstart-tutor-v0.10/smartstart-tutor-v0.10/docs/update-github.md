# Updating GitHub Pages to SmartStart v0.9

1. Download and extract `smartstart-tutor-v0.9.zip`.
2. Open the existing GitHub repository used for the tutor.
3. Choose **Add file → Upload files**.
4. Upload everything **inside** the extracted `smartstart-tutor-v0.9` folder.
5. Allow GitHub to replace the existing files.
6. Commit with a message such as `Complete Digital Hardware Practice module`.

The GitHub Pages address and the Advanced iFrame shortcode do not change. GitHub may take several minutes to publish the updated files.
