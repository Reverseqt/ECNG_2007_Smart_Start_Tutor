Logic Synthesis with Multiplexers

Use MUX data inputs as constants or remaining variables so that the selected input reproduces a Boolean function.

Part 1

Implement F=P+Q with a 4-to-1 MUX

Connect P and Q to the select inputs. For each select combination, set the corresponding data input equal to the required function output.

PQF=P+QMUX data input
000D₀=0
011D₁=1
101D₂=1
111D₃=1

The MUX output equals F because every selected D input matches the truth-table value.

Part 2

A 4-to-1 MUX exercise

Consider the K-map below. Use W and X as the select inputs. Read each row across and express it in terms of Z — the output happens not to depend on Y — then choose D₀ through D₃.

For each WX row, read the output as Z changes.

MUX realisation theorem

A 2ⁿ-to-1 MUX can realise any (n+1)-variable logic function without gates other than any required inverters.
