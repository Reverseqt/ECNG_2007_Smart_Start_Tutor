Part 2

Why priority encoders exist

A basic encoder assumes one active input. If several inputs are asserted, the result is ambiguous; a priority encoder resolves this by selecting the highest-priority request.

Original distinction retained

A priority encoder assigns priority to input lines so that, when multiple requests are asserted, the output gives the number of the highest-priority requester.
