Binary Values and Place Value

A byte is eight bits and 256 patterns. Deciding that those patterns mean numbers is the first act of data representation.

Home / Data Representation / Binary Values and Place Value

Part 1

Giving a pattern a numeric meaning

Eight bits give 256 patterns. Reading them as an unsigned number is one choice of meaning.

Module 1 established that a byte is eight bits and can take 256 distinct patterns. It said nothing about what a pattern means. Here we make the most common choice: treat each column as a place value, doubling from right to left, and add up the columns that hold a 1.

1286432168421
Binary00000000
Unsigned decimal0
Hexadecimal0x00

Unsigned is only one interpretation. The same eight bits can carry a signed value, a BCD pair, part of a floating-point number or an ASCII character — each covered later in this module.
