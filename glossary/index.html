Glossary

Definitions of the terms used throughout the eight modules.

A B C D E F G H I J K L M O P R S T

A

ALU
Arithmetic and logic unit: a block computing several functions of its operands, one of which is selected by a function code.
Analogue
Continuously variable signals or data.
ASCII
American Standard Code for Information Interchange: a seven-bit code containing 128 character and control-code values.
Axiom
A basic statement accepted as true within a formal system.

B

Biased (excess-k) representation
A signed representation in which the stored pattern is the value plus a fixed bias. It preserves the ordering of the underlying values, which is why IEEE 754 uses it for exponents.
Biased exponent
An exponent stored after adding a fixed bias, such as 127 in IEEE 754 single precision.
Binary-coded decimal (BCD)
An encoding in which every decimal digit is represented independently by a four-bit binary code word.
Bistable
A feedback circuit with two stable complementary states.
Bit
A binary digit that can hold one of two states, commonly represented as 0 or 1.
Boolean algebra
An algebraic system for variables with two states and operations such as AND, OR and NOT.
Bus contention
A harmful condition in which active outputs attempt to drive a shared conductor to different logic states.
Byte
A group of eight bits.

C

Canonical product of sums
A logical product containing the maxterms associated with every truth-table row for which the function is 0.
Canonical sum of products
A logical sum containing the minterms associated with every truth-table row for which the function is 1.
Characteristic equation
An equation specifying a sequential device’s next state as a function of present state and inputs.
Clock
A periodic signal used to coordinate state changes in synchronous circuits.
CMOS
Complementary metal–oxide–semiconductor logic using complementary n-channel and p-channel MOSFET networks.
Combinational circuit
A circuit whose current outputs depend on its present inputs and not on stored state.
Comparator
A combinational circuit that indicates whether one binary word is less than, equal to or greater than another.
Complement
The opposite Boolean state. The complement of 0 is 1 and the complement of 1 is 0.

D

D latch
An enable-controlled storage element whose next state follows D while enabled.
DC noise margin
The guaranteed voltage difference between a driver’s output limit and the receiving input threshold.
Decoupling capacitor
A capacitor placed close to an IC between power and ground to supply short switching currents and reduce supply disturbance.
Demultiplexer
A circuit that routes one data input to one of several outputs selected by a binary code.
Digital
Represented using a defined set of discrete states.
Distinguished 1-cell
A K-map 1-cell covered by only one prime implicant.
Dual
The Boolean expression produced by interchanging AND with OR and 0 with 1, while leaving variables and complements unchanged.

E

Encoder
A circuit whose one-hot input is represented by an n-bit binary output.
Essential prime implicant
A prime implicant that covers at least one distinguished 1-cell.
Exclusive-OR (XOR)
A function that is 1 when its inputs differ. It forms the sum bit of an adder and the inequality test of a comparator.

F

Fanout
The maximum number of similar input loads that an output can drive while meeting all voltage and current limits.
Fixed point
A representation in which the radix point is assumed to remain at a fixed position.
Flip-flop
An edge-triggered storage element that changes state with respect to a clock transition.
Floating input
An input not held at a defined voltage and therefore susceptible to leakage, coupling and noise.
Floating point
A representation using a significand and exponent so that the radix point can effectively move.
Free-wheeling diode
A diode that provides a safe current path for stored inductive energy after a switch opens.
Full adder
A circuit adding two bits and a carry-in to give a sum and a carry-out.

G

Glitch
A short, unintended pulse produced while a circuit is changing between steady states.
Gray code
A code ordered so that adjacent values differ in exactly one bit.

H

Half adder
A circuit adding two bits to give a sum and a carry, with no carry input.
Hazard
A circuit condition that can produce a glitch because signal paths have different propagation delays.
High impedance
A tri-state output condition in which the device behaves approximately as if disconnected from the shared signal.

I

Integrated circuit
A semiconductor chip containing interconnected electronic components, usually implemented using transistors.

J

JK flip-flop
A flip-flop in which J=K=1 commands the stored state to toggle.

K

Karnaugh map
A Gray-code arrangement of truth-table cells used to identify adjacent minterms and simplify Boolean functions.

L

Literal
A Boolean variable or its complement.
Lookup table (LUT)
Addressable storage holding the output column of a truth table, addressed by the function inputs. The basis of logic implementation in an FPGA.

M

Maxterm
A normal sum term containing every variable exactly once and evaluating to 0 for one input combination only.
Mealy machine
A state machine whose outputs depend on present state and current inputs.
Minterm
A normal product term containing every variable exactly once and evaluating to 1 for one input combination only.
Moore machine
A state machine whose outputs depend only on present state.
MOSFET
Metal–oxide–semiconductor field-effect transistor: a voltage-controlled device widely used as a digital switch.
Multiplexer
A data selector that connects one of several inputs to a single output according to select inputs.

O

Open collector / open drain
An output capable of actively pulling a line LOW or releasing it, normally used with an external pull-up resistor.

P

Petrick’s method
An algebraic method for finding all combinations of prime implicants that cover a Boolean function.
Prime implicant
A largest valid implicant that cannot be expanded without including a 0-cell.
Priority encoder
An encoder that resolves multiple active requests by assigning an input priority.
Product of sums (POS)
An AND operation applied to two or more sum terms.
Pull-up resistor
A resistor that gives a signal a default HIGH level while permitting another device to pull it LOW.

R

Radix
The base of a positional number system.
Register
A collection of two or more flip-flops sharing a common clock.
Ripple-carry adder
Full adders chained so that each carry-out becomes the next carry-in.

S

Schmitt trigger
An input circuit with separate rising and falling thresholds, providing hysteresis and rejecting slowly changing or noisy signals.
Seven-segment display
A display that forms decimal digits by illuminating combinations of seven labelled segments.
Sign-magnitude
A signed representation in which the leading bit gives the sign and the remaining bits give the magnitude. It has two representations of zero.
Sink current
Current flowing into a pin or device.
Source current
Current flowing out of a pin or device.
State
The stored values that summarise the relevant past behaviour of a sequential system.
State diagram
A graphical representation of states and directed transitions.
Static-0 hazard
A possible momentary 1 during a transition where the steady output should remain 0.
Static-1 hazard
A possible momentary 0 during a transition where the steady output should remain 1.
Sum of products (SOP)
An OR operation applied to two or more product terms.

T

Theorem
A statement that can be proved from axioms and previously established results.
Transition table
A table listing next state for each present-state and input combination.
Tri-state logic
Logic with three output conditions: LOW, HIGH and high impedance.
Truth table
A table listing all possible input combinations and the corresponding outputs of a function.
TTL
Transistor–transistor logic, a bipolar-junction-transistor logic family traditionally operated from a 5 V supply.
Two’s complement
A signed representation in which the leading column carries a negative weight. It has a single zero and allows ordinary binary addition to work on signed values unchanged.
