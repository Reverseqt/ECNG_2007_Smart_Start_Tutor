Part 1

One block, several functions

The arithmetic and logic unit is the computational element at the centre of a processor.

Each circuit considered so far performs a single operation. An arithmetic and logic unit performs several, selected at the time of use by a function select code. That code is what a program instruction ultimately resolves to.

The construction is straightforward: compute every candidate result in parallel, then use a multiplexer to select the one indicated by the function code.

What this ALU is made of

  • A bank of AND gates, one per bit
  • A bank of OR gates, one per bit
  • The four-bit ripple-carry adder from the previous activity
  • A multiplexer selecting which result reaches the output

Part 2

Subtraction, already solved

Subtraction is obtained by the method established in the preceding activity.

Subtractors showed that a single SUB control line turns an adder into a subtractor: XOR gates invert B, and the same line feeds the carry-in to supply the “add 1” of two’s complement. The ALU needs nothing more than that.

So the arithmetic half of this ALU is one adder and four XOR gates. The SUB line is simply driven by the function select code: it is 0 for ADD and 1 for SUB.

What the function select actually controls

  • S1 chooses arithmetic (1) or logic (0).
  • S0 picks which of the pair: OR against AND, or SUB against ADD.
  • For arithmetic, S0 is also the SUB line feeding the XOR gates and the carry-in.
