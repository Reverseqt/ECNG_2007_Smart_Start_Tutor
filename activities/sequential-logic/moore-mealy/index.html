Moore and Mealy State Machines

Compare the two standard state-machine models and how each produces its outputs.

Home / Sequential Logic / Moore and Mealy State Machines

Part 1

Two state-machine structures

Both structures use next-state logic and state memory; they differ in how outputs are produced.

Moore machine

Inputs
→
Next-state logic
→
State memory
Output = F(state)

Mealy machine

Inputs + state
→
Next-state and output logic
→
State memory
Output = F(state, input)
