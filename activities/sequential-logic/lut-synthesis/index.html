Synthesis with Lookup Tables

A lookup table realises a truth table directly as stored data rather than as gates. This is the mechanism by which field-programmable devices implement logic.

Home / Sequential Logic / Synthesis with Lookup Tables

Part 1

Storage that behaves like a gate

A lookup table is storage arranged so that its address lines are the inputs of the function.

A lookup table applies addressable storage to combinational logic. Rather than computing a function with gates, the results are stored and subsequently read out.

Consider any three-input function. Its truth table has eight rows and a single output column. Place those eight output bits in eight storage cells and connect the three inputs to the address lines. Applying an input then causes the addressed cell to drive the output. The truth table has ceased to be a description of the circuit and has become the circuit itself.

Lookup tables in practice

This is the mechanism by which a field-programmable gate array implements logic. Such a device contains many thousands of small lookup tables, typically of four to six inputs each, and programming it consists of loading bits into those cells. No gates are rearranged, since there are no gates to rearrange: only stored bits and the multiplexers that read them.

Part 4

Four ways to build the same function

All four have now been treated.

Four methods of implementing a function have now been presented. All produce identical outputs; they differ in what each consumes.

The lookup table is the only method in which altering the function requires no alteration to the circuit. This property is what renders a field-programmable device reconfigurable, and it is what justifies the storage the other three methods avoid.

The saving is not without cost. Gate synthesis exploits structure within a function in order to reduce it; a lookup table disregards structure and requires 2n stored bits irrespective of the function's complexity. Lookup tables are therefore kept narrow and cascaded rather than widened.
