Worked example

From a logic circuit to a state diagram

An enabled two-bit counter is developed step by step.

  1. Determine the excitation equations D₀ and D₁ from the combinational logic.
  2. Substitute the D flip-flop characteristic equation Q*=D.
  3. Construct the transition table from the transition equations.
  4. Add the output equation MAX=Q₁Q₀EN.
  5. Draw the labelled Mealy state diagram.
