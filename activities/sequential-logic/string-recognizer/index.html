Original design example

Finite string pattern recogniser

Assert Z whenever the latest three inputs are 010, provided the sequence 100 has never occurred.

Problem statement: one input X and one output Z. Detect 010; once 100 is observed, enter a locked state in which Z remains 0 until reset.

State meaning

Why seven states?

The original derivation retained only the suffix information needed to recognise 010 or determine that 100 has occurred.

StateCodeStored information
RESET000No useful suffix yet
S1001Suffix 0
S2010Suffix 01
S3011Sequence 010 has just been retained
S4100Suffix 1
S5101Suffix 10
S6110Forbidden sequence 100 has occurred; locked

The machine retains the three most recent bits, asserts its output on the sequence 010, and latches permanently into a stop state on 100.
