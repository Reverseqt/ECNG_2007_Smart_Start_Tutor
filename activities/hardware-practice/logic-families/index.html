Part 3

Calculate current-limited fanout

Interfacing is not only about voltages. One output can only supply so much current.

A driving output has to source or sink the input current of every gate connected to it. Fanout is how many inputs one output can feed and still meet its guaranteed voltages. Enter data-sheet current magnitudes; the smaller of the HIGH- and LOW-state ratios sets the limit.

Calculated fanout20 loads

Note the direction convention: a pin sources current when current flows out of it and sinks current when current flows into it. Because a CMOS input draws almost no current, it permits a considerably higher fanout than a TTL input.
