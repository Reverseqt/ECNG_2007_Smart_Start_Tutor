Part 1

NMOS and PMOS transistors

CMOS stands for Complementary Metal-Oxide-Semiconductor. Complemantary means that it uses both NMOS and PMOS transistors to implement logic functions.

CMOS logic gates are built from two complementary networks of transistors: a pull-up network of PMOS transistors, and a pull-down network of NMOS transistors. The pull-up network connects the output to the positive supply voltage when the output should be HIGH, while the pull-down network connects the output to ground when the output should be LOW.

In a CMOS gate, the pull-up and pull-down networks are designed such that they never conduct at the same time, which minimizes power consumption. The output is determined by the combination of inputs applied to the gate, which control the transistors in both networks.

A PMOS transistor turns on when its gate voltage is sufficiently below its source voltage. Define the source-to-gate voltage as \(V_{SG} = V_S - V_G\).

A conducting channel forms between the source and drain when: \[ V_{SG} > |V_{TP}| \] where \(|V_{TP}|\) is the magnitude of the PMOS threshold voltage. In the ideal switch model, the transistor is off when \(V_{SG} \le |V_{TP}|\).

An NMOS transistor turns on when its gate voltage is sufficiently above its source voltage. Define the gate-to-source voltage as \(V_{GS} = V_G - V_S\).

A conducting channel forms between the source and drain when \[ V_{GS} > V_{TN}, \] where \(V_{TN}\) is the NMOS threshold voltage. In the ideal switch model, the transistor is off when \(V_{GS} \le V_{TN}\).

Part 2

CMOS inverter

NOT gates simply accept an input and outputs its opposite.

A CMOS inverter uses a PMOS to pull the output up to the supply voltage \(V_{DD}\) and an NMOS to pull it down to ground. Both gates receive the same input voltage \(V_{\mathrm{in}}\), and both drains connect to the output \(V_{\mathrm{out}}\).

The PMOS source is at \(V_{DD}\), while the NMOS source is at \(0\,\mathrm{V}\). That gives each transistor a different turn-on condition.

\[ \begin{aligned} \text{PMOS on:}\quad & V_{SG} = V_{DD} - V_{\mathrm{in}} > |V_{TP}| \\[4pt] \text{NMOS on:}\quad & V_{GS} = V_{\mathrm{in}} > V_{TN} \end{aligned} \]

Part 3

CMOS NAND and NOR gates

NAND outputs 0 only when both inputs are 1. NOR outputs 1 only when both inputs are 0.

A two-input CMOS gate has a PMOS pull-up network that connects the output to \(V_{DD}\) (logic 1) and an NMOS pull-down network that connects it to ground (logic 0). A series path conducts when both transistors conduct. A parallel network conducts when either branch conducts.

CMOS NAND

The NMOS transistors are in series, so the pull-down path is complete only when both inputs are 1. The PMOS transistors are in parallel, so either input being 0 completes a pull-up path.

\[ Y_{\mathrm{NAND}} = \overline{A \land B} = \overline{A} \lor \overline{B} \]

CMOS NOR

The NMOS transistors are in parallel, so either input being 1 completes a pull-down path. The PMOS transistors are in series, so the pull-up path is complete only when both inputs are 0.

\[ Y_{\mathrm{NOR}} = \overline{A \lor B} = \overline{A} \land \overline{B} \]

Part 4

CMOS XOR Gate

A XOR gate produces a high (1) output only when the two inputs are different.

The CMOS XOR gate in the parity circuit uses two transmission gates as switches. One connects \(B\) to the output, and the other connects its inverse, \(\overline{B}\). Each transmission gate uses a PMOS and an NMOS in parallel so it can pass either a logic 0 or a logic 1.

Two CMOS inverters generate \(\overline{A}\) and \(\overline{B}\). The signals \(A\) and \(\overline{A}\) control which path conducts.

  • When \(A=0\), the output follows \(B\).
  • When \(A=1\), the output follows \(\overline{B}\).
\[ \begin{aligned} Y &= \begin{cases} B & \text{if } A=0, \\ \overline{B} & \text{if } A=1 \end{cases} \\[6pt] &= (\overline{A}\land B)\lor(A\land\overline{B}) \\ &= A\oplus B. \end{aligned} \]

The circuit outputs 1 for \(01\) and \(10\), and 0 for \(00\) and \(11\).

Part 5

3-bit Parity Generator

A 3-bit parity generator produces an even parity bit for a 3-bit input.

A 3-bit even-parity generator uses two XOR gates to determine whether an extra 1 is needed to make the total number of 1s even.

An XOR gate outputs 1 when its inputs differ. The first XOR combines \(A\) and \(B\) to produce \(X\). A bar means NOT, \(\land\) means AND, and \(\lor\) means OR.

\[ X = A \oplus B = (\overline{A} \land B) \lor (A \land \overline{B}) \]

The second XOR keeps \(X\) when \(C=0\) and flips it when \(C=1\).

\[ P = \underbrace{(A \oplus B)}_{X} \oplus C = (\overline{X} \land C) \lor (X \land \overline{C}) \]

The complement \(\overline{X} = (\overline{A} \land \overline{B}) \lor (A \land B)\) is 1 when \(A\) and \(B\) match. Substituting the expressions for \(X\) and \(\overline{X}\) gives

\[ \begin{aligned} P ={}& (\overline{A} \land \overline{B} \land C) \\ &\lor (\overline{A} \land B \land \overline{C}) \\ &\lor (A \land \overline{B} \land \overline{C}) \\ &\lor (A \land B \land C). \end{aligned} \]

These four terms correspond to 001, 010, 100, and 111, so \(P=1\) exactly when the inputs contain an odd number of 1s.
