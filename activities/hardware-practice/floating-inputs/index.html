Unused and Floating Inputs

Observe why an unconnected input is unpredictable and compare pull-up, pull-down and tied-input remedies.

Part 1

Watch a floating input

An unused input is not held at a fixed voltage and may take either state according to noise and stray coupling.

Floating mode deliberately changes the simulated input to represent unpredictable pickup.

Part 2

Choose a deliberate state

Solution 1: resistor to a rail

A pull-up or pull-down gives the input a defined default level while allowing another device to override it. A 1 kΩ–10 kΩ range is typical for CMOS; the actual selection depends on the family and circuit.

Solution 2: tie to a used input

For some multi-input gates, an otherwise unused input may be connected to another valid input. This is only appropriate when it preserves the intended Boolean function.

Never assume an unused input is automatically 0. Consult the device data sheet and ensure every input is driven to a valid level.
