Compound Truth Tables

Build a step-by-step truth table for a compound function, then compare the function with its dual.

Home / Boolean Design / Compound Truth Tables

Part 1

Build a table one operation at a time

A compound expression is easier to evaluate when each parenthesised operation receives its own column.

Original function

F = ((X · Z) · (X · Y) + (Z + X))

  1. Calculate X · Z.
  2. Calculate X · Y.
  3. AND those two intermediate results.
  4. Calculate Z + X.
  5. OR the two major terms to obtain F.
